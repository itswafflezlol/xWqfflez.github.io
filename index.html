Who I am

wafflez
aka ilykeelon · itswafflez_ on Discord

yo, im waffles! also known as ilykeelon. i manage and own Minecraft servers and networks. been doing it for over 7 years and it's only gotten more interesting as time goes on.

what started as just playing on servers turned into owning them, then managing them, then helping other people run theirs. one thing led to another and now it's basically what i do.

network management

running a network means a lot of moving parts. proxy setup, server routing, load balancing, keeping everything stable while players are online. velocity config, game server connections, cross-server sync, i handle all of it.

on the plugin side, it's making sure nothing conflicts, performance stays solid, and every server connects to each other.

plugin config is an actual skill

anyone can install a plugin. making it actually work for your server, not conflict with anything, and run smooth for what you need, that's where most people get stuck.

i've touched basically every category. economy, combat, permissions, events, chat, building. i get them working together and keep them that way.

development

skript isn't my main focus anymore, but i can still knock out systems when you need them. when plugins can't do something, scripting fills the gap. i've built everything from simple chat setups to full event mechanics with custom bosses, rewards, and countdowns.

i also know html and i'm learning java. that's where i wanna take things, actual plugin dev from scratch.
