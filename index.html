Who I am

wafflez
aka ilykeelon · itswafflez_ on Discord

yo, im waffles! also known as ilykeelon. i manage and own Minecraft servers and networks. been doing it for over 7 years and it's only gotten more interesting as time goes on.

what started as just playing on servers turned into owning them, then managing them, then helping other people run theirs. one thing led to another and now it's basically what i do.

network management

running a network means a lot of moving parts. proxy setup, server routing, load balancing, keeping everything stable while players are online. velocity config, game server connections, cross-server sync, i handle all of it.

on the plugin side, it's making sure nothing conflicts, performance stays solid, and every server connects to each other.

plugin config is an actual skill

anyone can install a plugin. making it actually work for your server, not conflict with anything, and run smooth for what you need, that's where most people get stuck.

i've touched basically every category. economy, combat, permissions, events, chat, building. i get them working together and keep them that way.

development

skript isn't my main focus anymore, but i can still knock out systems when you need them. when plugins can't do something, scripting fills the gap. i've built everything from simple chat setups to full event mechanics with custom bosses, rewards, and countdowns.

i also know html and i'm learning java. that's where i wanna take things, actual plugin dev from scratch.

Frequently Asked Questions

Common questions about services, pricing, and how ordering works.

How do I order a server setup?
Join the Discord server or DM itswafflez_ directly with what you need. We talk through scope, agree on a price, and I get started.
How much does a setup cost?
Most full setups land between $50 and $150 depending on scope. Smaller jobs like single-plugin config are cheaper. You get a quote before any work starts.
How long does a setup take?
Simple setups are usually done in a few days. Larger networks with custom systems can take one to two weeks depending on complexity.
What server types do you work with?
Survival SMP, Lifesteal, Lobby, Proxy networks, BoxSMP, Random Kits, event servers, RPG, economy servers, and anything else you can describe.
Do you work with Paper, Spigot, and Velocity?
Yes. PaperMC, Spigot, and Velocity proxy setups are the main stack, along with LuckPerms, EssentialsX, WorldEdit, FAWE, ItemsAdder, Nexo, Oraxen, PlaceholderAPI, TAB, and Vault.
Can you fix or optimize an existing server?
Yes. TPS troubleshooting, JVM flag tuning, PaperMC config optimization, and plugin conflict resolution are all part of what I do.
Do you offer support after the setup is done?
If something I configured breaks, I fix it. For bigger changes or new features after delivery, we can talk about additional work.
How do payments work?
All work is paid upfront: you pay first, then I start working. Pricing is agreed before payment so there are no surprises. See the for the full policy.

Still have questions?

DM me on Discord and I'll answer anything else.
